# Terminal Tools & Extensions

A list of modern CLI tools, TUI applications, and custom extensions used in the terminal workflow.

## Newly Added TUIs
- **Harlequin**: A TUI SQL IDE configured for DuckDB, Postgres, MySQL, and SQLite with Vim keybindings.
- **Posting**: A TUI HTTP client for testing APIs (a terminal alternative to Postman) with a matching Gruvbox theme.

## Modern CLI Tools (From Shell History)
- **bat**: A `cat` clone with syntax highlighting and Git integration.
- **btop**: A resource monitor that shows usage and stats for processor, memory, disks, network, and processes.
- **eza**: A modern, feature-rich replacement for `ls` with colors and icons.
- **fzf**: A lightning-fast command-line fuzzy finder for files, history, and more.
- **htop**: An interactive system-monitor process-viewer and manager.
- **jq**: A lightweight and flexible command-line JSON processor.
- **lazygit**: A simple terminal UI for git commands, making version control more visual.
- **rg (ripgrep)**: A line-oriented search tool that recursively searches directories for a regex pattern much faster than `grep`.
- **tmux**: A terminal multiplexer that allows multiple terminal sessions to be accessed simultaneously in a single window.
- **zoxide**: A smarter `cd` command that learns your habits and allows you to navigate faster.
